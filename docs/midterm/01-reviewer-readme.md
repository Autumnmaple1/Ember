# Ember 中期提交说明

Ember 是“持续角色陪伴＋共同活动”的单角色交互原型。本次重点是可继续的相处记录和《窗边的一页》共同创作闭环。

## 建议评审顺序

1. 阅读《Ember中期策划案.pdf》前两页了解目标与边界。
2. 解压整个压缩包，双击“开始展示.cmd”，浏览器打开 http://127.0.0.1:8765。
3. 按《演示讲稿.md》体验约 7 分钟的流程。
4. 查看《验收报告.md》以及真实模式运行说明，区分展示适配与实际模型能力。

## 启动条件

- Windows 10/11，现代 Chromium 浏览器，Python 3.11 或更高版本。macOS/Linux 可在 `source` 目录运行 `python3 demo/launch.py`。
- 首次运行如缺依赖，会在 `source/demo/runtime/.venv` 创建虚拟环境并安装已验证的 `demo/requirements.lock.txt`，需要互联网；准备好依赖以后，展示不需要模型、Docker 或网络。依赖范围另见 `demo/requirements.txt`。
- Windows 启动器会实际验证解释器是否可运行，自动查找项目虚拟环境、Conda 和已注册的标准 Python，跳过失效路径与商店别名，不依赖 `py -3` 默认选择。可运行 `source\demo\start.cmd --check-python` 只检查选中的解释器。
- 如果仍未找到 Python，可在 CMD 设置 `set "EMBER_PYTHON=你的python.exe完整路径"`，再运行入口；PowerShell 使用 `$env:EMBER_PYTHON='你的python.exe完整路径'`。路径可含中文或空格。错误的旧覆盖值应先清除。
- 端口占用时，在 `source` 中运行 `python demo/launch.py --port 8766`。关闭终端或 Ctrl+C 停止。
- 手动打开上述地址可处理浏览器未自动弹出的情况。不要用文件方式直接打开 index.html。
- 真实模式另需 Node.js、模型密钥及独立 pgvector 数据库；详见单独说明。

## 展示模式边界

页面持续显示黄色标识。界面、世界时钟、共同活动规则、收藏、约定、自习、版本同步使用项目实际代码。对话是按关键词选择的预设台词；记忆列表是合成样例；聊天持久化和存档是展示专用 JSON 适配器。**这不是对真实大模型、向量召回、语音或生产数据库恢复的测试。**

展示模式不生成声音。点击重播会收到明确提示。生产版本支持在线 TTS，但服务可用性需要现场验证。聊天框支持任意输入，但预设台词不具备任意理解能力。

所有样例均为合成数据；启动不读取上级 `.env`、业务聊天或业务数据库。所有新数据位于 `source/demo/runtime/showcase`。每次重启保留已保存的记录，活动暂停等待确认。正常启动跟随当前现实时间；读展示快照回到快照时间。

若要从全新样例开始，在 `source` 中运行 `python demo/launch.py --runtime demo/runtime/review-02`，使用一个新的目录名。不要删除原业务目录或数据库卷。展示快照与生产 `.ember` 格式不兼容。

## 已知限制

当前只有一个短共同项目。没有完整地图、复杂任务系统、云端常驻、移动端原生应用、账号体系或语音输入。角色“活人感”和再次使用意愿尚待真人研究验证。Live2D 模型来自既有仓库，原作者及具体授权待补充，不将其计为本项目原创美术。

源代码基线 e9634bc8，本包另含中期展示适配与文档变更；每个文件的 SHA256 见 manifest.json。压缩包不包含 Python/Node 运行时、密钥或私人聊天。
