## 复核方法

在依赖已准备好的独立环境运行 `python demo/check_showcase.py`，该检查另需 httpx（可 `python -m pip install httpx`），仅创建临时合成文件。浏览器检查为 `node utils/check_midterm.mjs`，需 Playwright、Chromium 和运行中的展示服务；可用 EMBER_DEMO_URL 指定端口。完整后端 pytest 必须使用独立测试数据库连接参数，不能随意连接真实业务库。

文档源为 docs/midterm/proposal.md，生成器为 utils/write_midterm_proposal.py。重新制作 Word 需要 python-docx、Pillow；PDF 需 LibreOffice 和 Poppler 渲染。源图包含本次合成展示截图，不包含私人记录。

运行 `python utils/build_midterm.py --package-only` 重新生成压缩包，前提是 output/midterm 中已有最终 Word、PDF 和验收报告。脚本按 Git 可见文件加额外路径过滤，排除密钥、业务数据、运行时、缓存和 Git 元数据；预构建前端单独加入。manifest.json 记录各文件 SHA256，清单自身不自校验。

解压到全新目录，核对清单后启动 demo/launch.py，重复浏览器主线。检查 ZIP 中没有 .env 实值、业务 state.json、聊天/记忆文件、数据库备份或 node_modules。首次缺依赖会联网安装，Python 运行时不包含在压缩包。

## 恢复与限制

### Windows 启动器修复复核

收到首次双击失败反馈后，发现旧入口仅判断 py 是否存在，可能命中失效的 Python 3.13t 默认注册。已改为 PowerShell 直接验证解释器版本和可执行路径，自动识别项目虚拟环境、Conda 与标准 Python，跳过商店别名；注册表只读取安装路径层级。解释器路径经参数传递，支持中文和空格，不再依赖 py -3 的默认选择。

复核包含：不设置 EMBER_PYTHON 自动发现、错误覆盖值返回失败、中文与空格路径、损坏的 py 默认配置绕过，以及通过 CMD 自动启动后执行完整浏览器主线。回归入口为 `python demo/check_windows_start.py`，只使用临时合成文件，不连接数据库。

展示存档是 JSON 快照，保存展示历史、状态、玩家记录、中期缓冲与时钟，不兼容生产 .ember，不声称实现生产数据库事务回滚。读档前保留展示备份。生产恢复流程另由 archive/manager.py 管理，不能用本演示结果替代其数据库恢复验证。

停止展示后，原项目目录和配置保持可用；回退不需要删除任何数据库卷。公开分发前需核验既有 Live2D 模型的来源和许可证，提交包已说明其不是本项目原创美术。
