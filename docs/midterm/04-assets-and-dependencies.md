# 素材与依赖说明

本提交包包含项目既有源代码与资源。技术依赖版本范围见 `source/requirements.txt`、`source/demo/requirements.txt`、`source/frontend/package.json`，前端安装使用 package-lock.json。Python/Node、Docker、模型权重及外部 API 服务没有打包。

React、Vite、PixiJS、pixi-live2d-display、FastAPI、PostgreSQL、pgvector、Edge TTS 等各有其上游许可证和使用条件；提交材料不改变这些条件。第三方依赖清单不能替代逐项许可证核验。

场景 SVG 位于 `frontend/public/scenes`，属于本项目界面实现。Live2D 位于 `frontend/public/models`，沿用既有模型；当前仓库缺少能确认原作者和再分发许可的完整记录，因此不能将其列为原创美术，也不能据此承诺商业使用权。正式公开发布或商业化前需补齐来源、作者署名与授权；无法取得许可时应替换。

角色与校园场景是项目设定，不代表现实院校或机构背书。展示对话、偏好和记忆均为合成样例，不包含参与者资料。项目尚未完成真人研究，没有可报告的真实用户留存或疗效数据。
