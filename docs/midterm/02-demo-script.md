## 现场处理

- 页面未打开：手动访问终端地址；端口被占用则用 8766 重新启动。不要临时接入业务数据库。
- 角色加载失败：保留文字和活动演示，说明 Live2D 渲染降级；不声称此时动画正常。
- 已存在活动：选择继续或保留片段；需要完全重复时使用新的 runtime 目录，避免覆盖已有成果。
- 操作未及时刷新：先等当前轮结束，使用同步按钮或刷新；不要反复创建同名存档。
- 真实模型或语音不可用：记录服务失败，回到展示模式讲解界面，并说明真实效果当场未验证。

## 答辩常见问题

“游戏性在哪里？”——当前通过材料选择、调查预算、不确定性处理和成果归属形成一个短闭环；尚不足以支持长期内容消耗，跨日项目是下一阶段。

“角色真的记住了吗？”——真实代码有短期上下文、中期来源摘要和长期向量记忆；历史隔离抽查曾成功编码与召回，但仍可能理解错误。展示记忆页只是样例，不能据此证明本次运行了模型。

“能一直运行吗？”——现阶段本机进程运行期间有效，尚未实现安全的云端常驻与手机入口。后续必须补账号、鉴权、密钥隔离、后台调度、备份和成本上限。
