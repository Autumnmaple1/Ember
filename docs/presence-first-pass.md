# 角色在场感：第一轮诊断与修正

日期：2026-11-02。反馈：角色缺少活人感，时空理解与交流距离不自然。

## 已找到的具体原因

1. `Brain._generate_reply` 将用户、助手和时间信息压成一条“以下是历史，请生成下一句话”的用户消息。模型接到的是整理材料的任务，真实的交谈轮次与最后一句输入失去原有结构。
2. 默认提示每轮都要求审查社交距离、对方意图和人设许可，并硬性压到通常 10–20 字。这容易产生短促确认、反复询问和机械的人设检查。
3. 回复前状态准备已实现，但 `state_update_prompt` 仍说“你已结束当前互动”，会让状态模型提前推演尚未发生的答复。
4. 状态失败回退把角色目标改成“确认当前活动与交流方式”，将服务故障转化为人物动机。后续回复容易围绕系统确认工作展开。
5. 当前时间虽有注入，历史消息之间间隔与跨日关系仍交给模型自行计算。位置未知、联系方式未确认等标志，又容易被理解成双方关系陌生。
6. 主动发言提示默认使用“偶遇”表述，即使此前已有连续交流，也可能重新制造开场。

这些是源码中的明确问题；没有用户提供的具体回复样本，不能断言它们解释了所有距离感。

## 本轮改动

- 新增 `brain/dialogue_context.py`：保留原始 user/assistant 轮次，最后一条真实输入不再附带任务包装。系统事实、消息时间索引与检索记忆进入系统上下文。
- 后端计算当前日期、时段、消息所属日期、与上一条用户消息的间隔及跨日数。区分连续交谈、长间隔、未知旧时间与时间回退；间隔是世界时间，不冒充用户现实等待时长。
- 长间隔后明确旧用户位置和即时活动只有历史意义。当前仍没有完整的地点证据过期系统；结构化场景展示未因此自动改成新的位置。
- 普通聊天不强制生成独白或审查社交距离，不硬性限制成极短确认；允许按内容说完整、表达偏好与不同意见。
- 未知物理位置只限制动作、可见性与共同经历，不妨碍普通对话，不要求每轮盘问位置或联系方式。
- 状态更新明确处于答复前，保持尚未完成的具体目标。失败回退保留同一会话中的原目标；离线或时间冲突时清空过时意图，不创造“确认协议”的人物任务。
- 主动发言改为围绕具体发现、已有话题或确认的约定，不再默认重新偶遇。
- 远程指代需要共同可见的来源；未提供的书页、代码或题目不因角色“正在读书”而自动成为模型已知材料。

没有增加模型调用阶段，没有改动业务数据库、删除记忆或自动重写用户现有状态文件。生效需重启后端，重新加载 YAML 与 Python 代码。

## 验证与观察

正式 Python 套件 216 项通过，其中新增 12 项上下文测试。覆盖原始角色与最后输入、跨日、无时间旧记录、非法时间、回退、主动消息、中断标记、真实 Brain 调用路径和状态失败回退。

自动测试使用临时配置与独立 `ember_test_*` 数据库。本次没有修改前端，无需通过重新执行前端套件来推断对话质量。

另用 `utils/smoke_presence.py --real-model` 完成四个合成情境，并针对远程共同指代再检查一轮，共五次真实对话。使用临时角色状态，不读取业务聊天、不访问业务数据库、不生成 TTS。

| 情境 | 实际观察 |
|---|---|
| 连续讨论一个省略步骤 | 接续具体话题，没有重新开场；仍会在缺少原文时补充推测 |
| 昨晚告别、今天下午继续 | 能接续昨天的话题；首轮出现远程“是不是这里”式指代 |
| 地点未知、分享程序优化结果 | 直接回应优化，没有先盘问位置 |
| 微信远程、请求看桌上的书 | 明确无法看见，要求提供封面或书脊文字 |
| 增加共同指代约束后再次跨日 | 未再使用“是不是这里”，但仍补出未提供材料中的“归纳假设”细节 |

这不是有统计意义的质量测评，也没有做相同随机条件的 A/B 对照。最后一项说明材料理解仍可能幻觉，不能以“调用完成、场景没变”判定所有事实与表现均正确。本轮只能确认清除了几项明确的流程矛盾；实际活人感仍需真人对话评估。

## 下一层问题

当前状态以情境、心情、轨迹与目标字符串为主，尚不足以表达连续生活。下一轮应围绕一个完整的互动片段建设，优先级为：

1. **共同注意与进行中的话题**：双方具体在讨论哪份材料、哪些原文确实共享、哪个问题尚未回答、哪些决定已达成。没有来源的细节保持未知，不能靠人设补齐。
2. **可持续的角色行动**：活动从何时开始、当前进度、为何中断、接下来需要多久。由规则与事件推进，模型表达所处阶段；减少每轮凭空重建场景。
3. **空间与感知的证据**：双方最后明确位置、确认时间、交流媒介、共享对象和可执行动作。旧证据有时效，而关系熟悉程度不能由位置是否已确认推导。
4. **关系中的具体连续性**：记住双方怎么称呼、偏好如何形成、哪些事情还挂着；允许有主见和边界，不靠突然亲昵或编造往事提升熟悉感。

建议先以“围绕同一页材料聊完一次、离开后再回来继续”为验收片段，再扩展角色日程和长期行动。暂不通过更多 PAD 数值或每轮更多自我分析解决在场感。
