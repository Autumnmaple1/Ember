## 本次完成

- 默认舞台优先，可切换对话优先；最新对话、输入和连接状态常驻。
- 时间、角色位置、用户位置与交流方式分别展示；未知信息保持未知。
- PAD、目标、独白和近期轨迹进入辅助页面，主界面不再自动弹出独白。
- 多行输入、中文输入法保护、草稿与显示偏好持久化、即时发送反馈。
- 用户消息分为发送中、已接收、已保存、失败和结果待确认。已保存仅来自提交后的事件或历史查询。
- 稳定请求标识、明确重试、服务器去重；重试核对缓存、待写文件或已保存消息，避免再次触发同一段对话。
- 历史加载错误与重试，有限自动退避重试，重连同步；分页保持阅读锚点，新消息不会把阅读中的用户拉回底部。
- 统一音频队列；关闭声音清空当前与待播声音，迟到音频失效；手动重播绑定请求和消息，仅返回请求页面。
- 语音生成剥除独白与 response 标签；合成失败返回对应请求的错误。
- Live2D 使用容器尺寸和 ResizeObserver，模型失败仍可文字聊天；支持重新加载和 WebGL 丢失后的恢复入口。
- 移除全局右键触摸；现有模型没有 HitAreas。语义动作填入草稿，发送后才由角色回应。
- 设置支持对白字号、声音和服务状态；原有声音偏好继续沿用，新浏览器默认关闭自动声音。
- 原生 dialog 提供弹窗焦点约束、Esc 与焦点返回；存档操作中禁止误关。
- 存档样式适配新主题，时间倍率改为预览后明确应用，失败恢复实际值。
- 深浅主题、窄屏、触控目标与减少动态偏好支持。

## 启动与兼容

需同时使用本次前后端版本，重启旧后端后才能获得发送确认与指定消息重播。

后端仍在 Ember Conda 环境执行 `python server.py`；前端在 `frontend` 执行 `npm run dev`。数据库配置沿用现有配置，本次没有修改结构、迁移业务数据或删除任何卷。

`VITE_API_BASE_URL` 控制后端地址，默认 `http://localhost:8000`。前端开发端口继续使用 5173。

浏览器偏好键：`autoPlay`（兼容旧版）、`ember.draft.v1`、`ember.fontSize.v1`、`ember.view.v1`。草稿仅保存在当前浏览器，不作为角色记忆。

- `npm test`：13 项通过，覆盖历史合并、输入法、HTTP 超时/取消、声音队列及迟到播放、发送确认、断线后完整回复恢复。
- `npm run test:browser`：合成接口与 WebSocket，12 类场景通过；验证 320/390/768/1366/1920px 的两种视图，分页锚点、草稿、发送失败、静音、重播、弹窗与倍率回滚。
- 浏览器加载现有 Live2D 素材成功；模拟 WebGL 丢失后重新加载成功；未调用真实模型或语音接口。
- `python utils/validate_ui_protocol.py`：6 项模拟协议检查通过，包含定向语音、正文清理、幂等重试、错误关联及写入失败不报告已保存。
- Docker 就绪后已补跑完整 `python -m pytest tests -q`：本阶段 116 项全部通过，包含真实数据库提交事件、重试恢复与保存状态。测试只创建并清理 `ember_test_*` 临时数据库，未修改业务记录。
- 生产构建通过，仍有 Pixi/Live2D 大包提示；后续按角色模块拆包和资源测量优化。

浏览器测试可使用已安装的 Playwright，或通过 `PLAYWRIGHT_MODULE_PATH` 指向外部 Playwright 包；`PLAYWRIGHT_CHROMIUM_EXECUTABLE` 可指定已有 Chromium。脚本自行启动并关闭临时 Vite，强制模拟后端地址，不会请求业务聊天接口。截图输出到被 Git 忽略的 `frontend/test-results/`。

## 本阶段边界

第一阶段当时没有实现真正的取消生成；该项已在后续轮次控制阶段补齐。专注活动状态机、结构化回忆册、新场景美术、精确身体触摸和存档任务进度协议仍待后续实现。

“邀请自习”只生成可编辑邀请；“回忆”当前展示带来源提示的近期轨迹。时间倍率暂留存档页面。存档加载仍沿用原有完整恢复和页面刷新流程，后续 M6 再统一改造。

第一阶段没有实现跨标签页播放所有权或会话纪元。断线恢复、声音失效和当前消息关联已处理；存档与后端重启时的完整事件隔离由后续协议阶段完成。
